# 4_品質チェック

## 役割
公開前の最終確認を担当します。事実・表現・体裁の3観点で記事を検品します。

## インプット
- `2_記事生成` の下書き本文
- `3_タイトル` の採用タイトル

## アウトプット
- チェックリストの記入済みファイル（指摘事項と修正結果）

## チェック観点
- **事実**: 数値・固有名詞・引用元URLが正しいか、出典を明記しているか
- **表現**: 誤字脱字、表記ゆれ、断定しすぎ／曖昧すぎな表現がないか
- **体裁**: 見出し階層、改行、箇条書き、画像の配置、リンク切れ
- **権利**: 引用範囲、画像のライセンス、他社サービス名の表記

## 進め方
1. 上記4観点を順に確認し、指摘をファイルに記録する
2. 修正が必要なものは `2_記事生成` へ差し戻す
3. 問題がなければ公開し、`5_SNS集客` へ渡す

## ファイル命名
`YYYY-MM-DD_テーマ名_check.md`
