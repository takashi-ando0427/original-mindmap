# 2_記事生成

## 役割
リサーチメモの構成案をもとに、note へ掲載する本文を執筆します。

## インプット
- `1_リサーチ` のリサーチメモ（想定読者・結論・構成案）

## アウトプット
- 記事の下書き（Markdown）
  - 目次（各見出しへ飛べるリンク付き） → リード文 → 本文（見出し単位） → まとめ → 次のアクション導線
- 記事内で使う図表の画像（比較表・手順図など）

## 進め方
1. 構成案の見出しをそのまま Markdown の見出しとして置き、冒頭に目次（アンカーリンク付き）を用意する
2. 各見出しの下に、結論 → 理由 → 具体例の順で書く
3. 一文を短くし、専門用語には注釈を添える
4. 比較や手順は表・図におこし、画像として書き出して差し込む
5. 書き上げたら `3_タイトル` へ渡す

## ファイル命名
- 本文: `YYYY-MM-DD_テーマ名_draft.md`
- 図表画像: `YYYY-MM-DD_テーマ名_fig1.png`（連番）

## 備考
- 公開が完了した記事は、冒頭に公開URLを追記したうえで `note事業部/README.md` の運用ルールに従って管理します。
