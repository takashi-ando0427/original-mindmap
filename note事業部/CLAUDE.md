# note事業部 共通ルール

このファイルは、note事業部で作業するすべての担当（人・AIを問わない）が守る共通ルールです。
`note事業部/` 配下で作業するときは、各フォルダの README より先に、まずこのルールを読んでください。
各工程の具体的な手順は `1_リサーチ/` 〜 `5_SNS集客/` の README に記載しています。

## 誰が、誰に向けて書くか
- 発信者：たかし
- ジャンル：AIと副業
- 読者：これから副業を始めたい会社員
- 読者の前提知識：ChatGPTは触ったことがある。それ以上のツールは知らない前提で書く

## 文体
- 文末はですます調。フレンドリーに
- 専門用語は避ける。どうしても使うときは必ず「簡単に言うと〜」で噛み砕く
- 中学生が読んでも分かるレベルを基準にする
- 1文は短く。1つの文で2つ言おうとしない
- 感想の語尾（〜だと思います）を並べない。事実で書く

## 書いてはいけないこと
- 根拠のない数字を書かない
- 「必ず稼げる」「誰でも」「絶対」などの断定は使わない
- 他の職業や他社のサービスを下げて持ち上げない
- 体験していないことを体験したように書かない
- 収益や効果を保証しない

## 一貫させること
- note と SNS で、人物像とトーンをそろえる
- 一人称・呼びかけ・絵文字の使い方を途中で変えない
- 同じものは同じ名前で呼ぶ（途中で言い換えない）

## 仕事の進め方
- 迷ったら、勝手に決めずに質問する
- 成果物は必ず自分の担当フォルダの中に保存する
- 前の担当の成果物がないときは、想像で埋めずに「足りない」と報告する
