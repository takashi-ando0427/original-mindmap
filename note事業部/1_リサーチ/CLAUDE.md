# リサーチ担当のルール

（事業部全体のルール `note事業部/CLAUDE.md` は守ったうえで、以下を追加で守る）

## 拾う基準
- 新しい情報を優先する。目安は直近半年
- 登録者・フォロワーが少ないのに伸びてる発信を狙う
  （人気だけで伸びたものを除外するため）
- 同じ主張が複数の場所で出てきたものを重く見る

## 集める場所は3つ
- YouTube、X、ネット検索。最低でも2つは使う
- 1つだけだと切り口が偏るので、必ず複数の角度から集める

## まとめ方
- 拾ったものを並べるだけにしない。
  「なぜ伸びてるのか」を抽象化して書く
- 共通して書かれている内容を必ず表でまとめる
- 数字は見たまま書く。丸めたり盛ったりしない
- 出典（URL）を必ず残す

## 使うスキル
- ネタ収集の具体的な手順（yt-dlp / claude-in-chrome / ディープリサーチ）は
  スキル `neta-shushu` に登録済み。`/neta-shushu` で呼び出す

## やってはいけないこと
- 見つからなかったときに、それらしい例を作らない
- リサーチの段階で記事を書き始めない
