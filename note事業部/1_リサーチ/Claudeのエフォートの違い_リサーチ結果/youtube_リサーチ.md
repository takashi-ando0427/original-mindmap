# YouTube リサーチ：Claudeのエフォートの違い

## 結論：この経路は実行できませんでした

想像で埋めることはせず、事実だけを記録します。

## 実行できなかった理由
1. **yt-dlp が導入されていない**
   実行環境に `yt-dlp` コマンドも Python モジュール `yt_dlp` も存在しませんでした。
2. **YouTube への通信が遮断されている**
   `https://www.youtube.com` への接続が、組織のネットワークポリシーにより拒否されました
   （エグレスプロキシが CONNECT を拒否：`connect_rejected`）。
   yt-dlp を導入しても、この環境からは動画情報を取得できません。

## 取得できなかった項目
- 直近半年の投稿動画の一覧
- チャンネル登録者数、再生数、投稿日
- 登録者が少ないのに伸びている動画の絞り込み
- 字幕による「中身」の把握

## 再実行する場合の条件
次のいずれかが必要です。
- YouTube への通信が許可された環境で、`yt-dlp` を導入して実行する
- 収集結果（動画URL・登録者数・再生数・投稿日・字幕）を人手で用意し、このファイルに貼る
