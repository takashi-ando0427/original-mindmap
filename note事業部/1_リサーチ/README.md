# 1_リサーチ

## 役割
記事のネタと切り口を決めるための情報収集を担当します。
「誰の、どんな悩みに、何を答える記事なのか」をここで確定させ、後工程が迷わない状態にします。

## インプット
- 発信テーマ・ターゲット（`note事業部/README.md`）
- 検索キーワード、note内の類似記事、SNSでの反応、自分の実務経験

## アウトプット
- リサーチメモ（1記事につき1ファイル）
  - 想定読者とその悩み
  - 記事で答えること（結論）
  - 参考にした情報源とURL
  - 構成案（見出しレベルの箇条書き）

## 進め方
1. キーワード・悩みを洗い出す
2. 既存記事を確認し、被らない切り口を決める
3. 結論を先に一文で言語化する
4. 見出し構成まで落とし込み、`2_記事生成` へ渡す

## 使うスキル
`neta-shushu`（ネタ収集）… 3経路からの収集手順とまとめ方。`/neta-shushu` で呼び出す。
定義は `.claude/skills/neta-shushu/SKILL.md`。

## ファイル命名
`YYYY-MM-DD_テーマ名_research.md`
