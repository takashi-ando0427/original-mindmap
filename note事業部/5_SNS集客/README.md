# 5_SNS集客

## 役割
公開した記事を SNS で届け、反応を記録して次の企画に還元します。

## インプット
- 公開済み記事のURLとタイトル

## アウトプット
- 告知投稿の文面（メインはスレッズ）とコメント欄用の文
- 投稿スケジュール
- 反応の記録（インプレッション、いいね、流入数、note のビュー・スキ・フォロワー増）

## 進め方
1. 記事の結論を1〜2文に要約した告知文を用意する
2. 公開直後・翌日・1週間後など、切り口を変えて複数回投稿する
3. 公開1週間後と1か月後に数値を記録する
4. 反応の良かったテーマを `1_リサーチ` へフィードバックする

## ファイル命名
`（テーマ名）スレッズ宣伝.md`（メイン投稿＋コメント欄用リンク文。数値記録も同ファイルに追記）
