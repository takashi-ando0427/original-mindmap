# スレッズ宣伝（SNS集客担当）

`note事業部/CLAUDE.md`（全体ルール）と `note事業部/5_SNS集客/CLAUDE.md`（担当ルール）を必ず守る。

- **インプット**：`2_記事生成/（テーマ名）記事.md`、採用タイトル、note の URL と価格
- **出力先**：`5_SNS集客/（テーマ名）スレッズ宣伝.md`

## 手順
1. 記事を読み、投稿で言うことを**1つ**に絞る（1本の投稿で2つ言わない）
2. メイン投稿を書く。リンクは本文に貼らない
3. コメント欄用のリンク文を別で書く。投稿文とコメント欄は必ずセットで出す
4. 【要確認】note の URL と価格を確認する。
   未公開・未定なら `（URL）` `（価格）` のプレースホルダーで作成し、
   公開後に差し替えるようユーザーに伝える
5. ファイルに保存し、投稿のタイミング案を添える

## 書き方
- メインはスレッズを想定する
- 語尾は「です」で終わらせず、「！」か柔らかい絵文字をつける
- 中身の数字やボリューム（章の数、手順の数など）は本文から拾って具体的に入れる。
  記事に書いていない数字は作らない
- 読者は「これから副業を始めたい会社員」。前提知識は ChatGPT を触ったことがある程度
- note と人物像・トーンをそろえる。一人称と絵文字の使い方を途中で変えない

## 使わない表現
- 「＝」を使った言い切り
- 「未経験から」
- 「◯時間→◯分」の時短アピール
- 煽らせる言い方（「知らないと損」「差がつく」）
- 収益や効果の保証、「必ず」「絶対」「誰でも」

## 出力の形
```markdown
# （テーマ名）スレッズ宣伝

## メイン投稿（1本目）
（本文。リンクは貼らない）

## コメント欄用
（リンク文。noteのURLと価格）

## 投稿タイミング案
- 公開直後 ／ 翌日 ／ 1週間後（切り口を変えて出す）

## 記録（公開後に追記）
- インプレッション ／ いいね ／ note のビュー・スキ・フォロワー増
```

## 2本目以降
- 同じ記事でも、切り口を変えて何度でも作れる
  （読者の悩み起点 / 手順の一部を公開 / 図表を見せる / 感想を紹介）
- 反応の良かったテーマは `1_リサーチ` へフィードバックする
