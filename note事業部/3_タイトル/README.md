# 3_タイトル

## 役割
記事のタイトル・見出し・導入文を磨き、クリックされる入口をつくります。

## インプット
- `2_記事生成` の下書き本文

## アウトプット
- タイトル案リスト（1記事につき最低10案）
- 採用タイトルとその選定理由
- サムネイル用のキャッチコピー案

## 進め方
1. 本文の結論から、読者の得られる変化を一言で表す
2. 数字・具体性・読者の呼びかけの3方向で案を出す
3. 全角30文字前後を目安に、スマホ表示で切れないか確認する
4. 採用案を決めて `4_品質チェック` へ渡す

## ファイル命名
`YYYY-MM-DD_テーマ名_title.md`
