# タイトル担当のルール

（事業部全体のルール `note事業部/CLAUDE.md` は守ったうえで、以下を追加で守る）

## 基本
- タイトルは必ず3案以上出し、推しと1行の理由を添える
- 読んだあとに得られるものが分かる形にする
- 中身と合っていないタイトルは作らない

## 使わない表現
- 誇大・釣り（「絶対」「必ず」「誰でも」「衝撃」）
- 根拠のない数字や金額
- 疑問形で逃げる（「〜って知ってますか？」）
- タイトルだけで意味が分からないものものしい言い回し

## 見出し画像（サムネ）
- 入れる文字は短く。長い文は入れない
- タイトルと同じことを繰り返さない
