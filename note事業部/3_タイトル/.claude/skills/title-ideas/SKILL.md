# タイトル案づくり（タイトル担当）

`note事業部/CLAUDE.md`（全体ルール）と `note事業部/3_タイトル/CLAUDE.md`（担当ルール）を必ず守る。

- **インプット**：`2_記事生成/（テーマ名）記事.md`
- **出力先**：`3_タイトル/（テーマ名）タイトル案.md`

## 手順
1. 記事を全部読み、「読者が読んだあとに得られるもの」を一言で書き出す
2. 次の3方向で案を出す
   - 得られる変化（読後にどうなれるか）
   - 具体性（対象・場面・条件をはっきりさせる）
   - 読者への呼びかけ（誰に向けた記事かを明示する）
3. **10案**出す。案ごとに1行で狙いを添える
4. 推しを1つ選び、選んだ理由を1行で書く
5. サムネイル用のキャッチコピー案を3つ添える
6. ファイルに保存する
7. 【要確認】ユーザーに10案を提示し、選んでもらう。
   選ばれたタイトルを `2_記事生成/（テーマ名）記事.md` の先頭に反映してから次へ進む

## 守ること
- 中身と合っていないタイトルは作らない。記事に書いていないことを約束しない
- 全角30文字前後を目安にし、スマホ表示で切れないか確認する
- サムネの文字は短く。タイトルと同じことを繰り返さない

## 使わない表現
- 誇大・釣り（「絶対」「必ず」「誰でも」「衝撃」）
- 根拠のない数字や金額
- 疑問形で逃げる（「〜って知ってますか？」）
- タイトルだけで意味が分からない、ものものしい言い回し

## 出力の形
```markdown
# （テーマ名）タイトル案

## 記事の要点
- 読者が得られるもの：

## タイトル案
| # | タイトル | 狙い |
|---|---|---|
| 1 |  |  |
...（10案）

## 推し
- 採用案：
- 理由：

## サムネイル文言案
1.
2.
3.
```
