# note事業部

## 概要
note（ https://note.com/ ）での情報発信を事業として立ち上げるための作業フォルダです。
記事の企画・執筆・公開・振り返りまでを、このフォルダ配下で一元管理します。

## 目的
- 発信テーマとターゲットを定義し、属人的でない運用ルールを整備する
- 記事のネタ出しから公開までのフローをリポジトリ上で可視化・記録する
- 公開後の反応（ビュー・スキ・フォロワー等）を蓄積し、次の企画に活かす

## フォルダ構成（予定）
```
note事業部/
├── README.md        # 本ファイル（事業部の概要・運用ルール）
├── 企画/            # 発信テーマ、ターゲット、ネタ出しメモ
├── 記事/
│   ├── 下書き/      # 執筆中の記事（Markdown）
│   └── 公開済み/    # 公開した記事の控えとURL
└── 分析/            # 公開後の数値記録・振り返り
```
※ 現時点ではフォルダのみ作成しています。上記の内訳は必要になった時点で追加します。

## 運用ルール（たたき台）
- 記事は Markdown（`.md`）で作成し、ファイル名は `YYYY-MM-DD_タイトル.md` とする
- 下書きが完成し公開したら `記事/下書き/` から `記事/公開済み/` へ移動し、冒頭に公開URLを記載する
- 数値の振り返りは公開から1週間後・1か月後の2回を目安に `分析/` へ記録する

## 関連
- 本リポジトリのマインドマップツール（`mindmap-tool/`）を、記事構成やテーマの整理に活用する
