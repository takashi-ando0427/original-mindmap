# note事業部

## 概要
note（ https://note.com/ ）での情報発信を事業として立ち上げるための作業フォルダです。
記事の企画・執筆・公開・振り返りまでを、このフォルダ配下で一元管理します。

## 目的
- 発信テーマとターゲットを定義し、属人的でない運用ルールを整備する
- 記事のネタ出しから公開までのフローをリポジトリ上で可視化・記録する
- 公開後の反応（ビュー・スキ・フォロワー等）を蓄積し、次の企画に活かす

## フォルダ構成
記事づくりの工程を、5つの役割フォルダに分けて管理します。番号順に進めるのが基本フローです。

```
note事業部/
├── README.md        # 本ファイル（事業部の概要・運用ルール）
├── 1_リサーチ/      # ネタ出し、想定読者・切り口・構成案の決定
├── 2_記事生成/      # 構成案をもとにした本文の執筆
├── 3_タイトル/      # タイトル・見出し・導入文の作成と選定
├── 4_品質チェック/  # 事実・表現・体裁・権利の最終確認
└── 5_SNS集客/       # 公開後の告知と反応の記録
```
各フォルダの役割・インプット／アウトプット・ファイル命名規則は、それぞれの README に記載しています。

## 運用ルール（たたき台）
- 成果物は Markdown（`.md`）で作成し、ファイル名は `YYYY-MM-DD_テーマ名_工程.md` に統一する
- 1本の記事に関する成果物は、同じ「テーマ名」で各工程フォルダに揃える
- 公開した記事は、下書きの冒頭に公開URLを追記する
- 数値の振り返りは公開から1週間後・1か月後の2回を目安に `5_SNS集客/` へ記録する

## 関連
- 本リポジトリのマインドマップツール（`mindmap-tool/`）を、記事構成やテーマの整理に活用する
